# Locked dependency closure for the Devign reproduction.

#   Python 3.12.7 / Windows 11 / NVIDIA RTX 4060 Laptop (8 GB) / CUDA 12.1

# This is the project's dependency CLOSURE, not a `pip freeze` of the developer's whole
# environment -- a freeze of an unrelated global env records 300+ packages the project never
# imports and tells you nothing about what must be reinstalled.
#
# torch comes from the PyTorch CUDA index, not PyPI:
#   pip install torch==2.5.1+cu121 --index-url https://download.pytorch.org/whl/cu121
#   pip install -r requirements.lock.txt
#
# tree-sitter 0.25.2 + tree-sitter-c 0.24.2 (grammar ABI 15) is pinned BEHAVIOURALLY by
# tests/test_grammar_canary.py: node types are half of every node feature, so a grammar bump
# silently changes the type vocabulary and therefore the model.
#
# scikit-optimize drives the Metrics+XGBoost baseline's Bayesian hyperparameter search
# (config `baselines.metrics_xgboost.bayes_opt_iters`). Without it that baseline trains at fixed
# hyperparameters and is WEAKER than the paper's; models/metrics_xgboost.py now says so loudly
# rather than falling back in silence.
